# Sistem Pakar

Aplikasi Sistem Pakar berbasis Vue 3 + TypeScript — studi kasus sistem pakar dengan fitur autentikasi, dashboard, dan komponen reusable.

## Features
* Login
* Dashboard
* Component Reusable
* Vuex State Management + Vue Router

## Tech Stack
* [Vue 3](https://v3.vuejs.org/)
* TypeScript
* [Tailwind CSS](https://tailwindcss.com/)
* Vuex 4 + Vue Router 4

## Requirement
* [Node.js + npm](https://www.npmjs.com/get-npm)

## Usage for development
1. Clone `https://github.com/fuadrifki/sistem-pakar.git`
2. `npm install`
3. `npm run serve`
4. Buka `localhost:8080` di browser
